# AFRICA ATONA artwork

All six original generated PNGs are preserved in `web/assets/`: logo, transparent app-icon, splash, website-hero, store-feature and social-poster. They use the African continent, winding road, destination pin and emerald/gold identity. The web header/favicon/manifest use the app emblem; the sidebar uses the hero; the Android download dialog uses the feature graphic; `/about.html` presents the full identity including social and splash artwork. Android bundles the original emblem and portrait splash and uses version 0.2.0-beta.

Images were created with the built-in image generator using the first logo as reference. The hero landscape is an illustration, not a map or actual road depiction. No store upload or production deployment is implied.
